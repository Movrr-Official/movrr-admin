### Approved impact — deployed

Count each session once, independently of rewards, ledger bonuses and settlement receipts. Actual historical verified rides remain eligible; no verification evidence was invented. Assigned-route distance and unverified GPS data do not supply impact.

Labels state an estimated average-car journey for the same distance, **not actual avoided emissions**. Equal car/cycle distance is a comparison assumption; no car substitution, lifecycle net cycling benefit, offsets or tree equivalents are inferred. Factor/eligibility/source/approval/deployment provenance is immutable and versioned; no arbitrary Admin factor is exposed. Historical financial/ride records and prior evidence are preserved.
